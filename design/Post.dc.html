エージェントが作ったブログは、なぜ公開されなかったのか

ppod #ai #agent #ci

このブログのリポジトリは、最初の版を丸ごとコーディングエージェントが作った。Astro のプロジェクトが用意され、記事のコレクションにスキーマが定義され、GitHub Actions のワークフローが置かれ、GitHub Pages へのデプロイまで書かれていた。ファイルを眺めるかぎり、やることは終わっているように見える。

サイトは公開されていなかった。

何が壊れていたか

原因は一つではなかった。順に出てきたので、順に書く。まず npm ci が落ちていた。package.json が astro ^5.2.4 を宣言しているのに、lock ファイルには 7.2.10 が入っていた。

これを直すと、次が顔を出した。タグページの import が一階層浅い。

import BaseHead from '../../components/BaseHead.astro';
ビルドは最後まで走るのに HTML が一枚も出ない。
